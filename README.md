# APCSA Fabric Modding Template

## Setup
You will need to change the [Maven](https://maven.apache.org/what-is-maven.html) *and* the folders to be your name

### -- THIS WILL BE REPLACED BY PYTHON SCRIPT --
Follow these steps:
1. Open `src/main/java`
2. Right click where it says `apcsa.template` and click `Refactor` and then `Rename`
3. If it asks to replace multiple packages, click `All Directories`
4. Go to the root of the project
5. Then, type `apcsa.[SCHOOL USERNAME]`

    Replace `[SCHOOL USERNAME`] with your username
5. Then, go to `gradle.properties` and change `maven_group=apcsa.template`

    Change it to be `maven_group=apcsa.[SCHOOL USERNAME]` like above
6. Now, go to `src/main/resources`
7. Right click `apcsa/`
8. You're done! Happy modding!
