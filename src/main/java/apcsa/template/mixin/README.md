# Mixins

## What is a mixin?
A mixin is code that gets injected into a pre-compiled Minecraft class

It's used a lot when changing basic Minecraft features
###### like changing how a stick works (Like the Paper Plugin Marsh made)

## Should I use mixins?
### It depends!

Sometimes you'll need to, but most of the time (and most likely for this clas) you won't need to!

Like stated earlier, you only really need to when changing something that isn't already accessible in Fabric
